# 拓扑数据结构字段说明文档

本文档旨在解释拓扑数据结构中各字段的含义和用途。

## 1. 主要数据结构

### 1.1 响应结构
```json
{
  "code": 1,
  "message": "查询成功",
  "data": {
    // 具体数据内容
  }
}
```

- `code`: 响应代码，1表示成功
- `message`: 响应消息，描述请求结果
- `data`: 实际的拓扑数据内容

### 1.2 data结构
```json
{
  "max_lat": 7.125,
  "min_lat": -15.875,
  "max_lon": 21.0,
  "min_lon": 0.0,
  "station_data": [...],
  "channel_data": [...]
}
```

- `max_lat`: 最大纬度值
- `min_lat`: 最小纬度值
- `max_lon`: 最大经度值
- `min_lon`: 最小经度值

## 2. station_data（站点数据）

每个站点包含以下字段：

### 2.1 基础信息字段
- `station_id`: 站点唯一标识符(UUID格式)
- `station_type`: 站点类型，如"station"
- `station_name`: 站点名称
- `vn_kv`: 额定电压(kV)
- `bus_name_list`: 母线名称列表
- `color`: 颜色标识(用于可视化)
- `lat`: 纬度坐标
- `lon`: 经度坐标
- `bus_id_list`: 母线索引列表
- `trafo_id_list`: 变压器索引列表
- `trafo_name_list`: 变压器名称列表
- `feedin_relation_bus_name_list`: 电源关联母线名称列表
- `sub_system`: 子系统tc算例文件编号(主拓扑专有字段)
- `sub_system_file_path`: 子系统tc算例文件完整路径(主拓扑专有字段)

### 2.1.1 站间联络成图扩展（可选）

- `trafo_display_list`: 站内主变 P/Q 展示用数组（联络图 `SvgLiaisonDrawioParser` 读取）；**图上不显示主变名**；多台**横向并排**，每台内 P/Q **竖排**。字段约定见 **`docs/站间联络JSON数据规范.md` §3.1**。

### 2.2 计算结果字段(res_*前缀)

#### 2.2.1 变压器相关结果
- `res_trafo_sum_p_hv_mw`: 高压侧总有功功率(MW)
- `res_trafo_sum_q_hv_mvar`: 高压侧总无功功率(Mvar)
- `res_trafo_sum_p_lv_mw`: 低压侧总有功功率(MW)
- `res_trafo_sum_q_lv_mvar`: 低压侧总无功功率(Mvar)
- `res_trafo_sum_loading_percent`: 总负载率(%)
- `res_trafo_max_p_hv_mw`: 高压侧最大有功功率(MW)
- `res_trafo_max_q_hv_mvar`: 高压侧最大无功功率(Mvar)
- `res_trafo_max_p_lv_mw`: 低压侧最大有功功率(MW)
- `res_trafo_max_q_lv_mvar`: 低压侧最大无功功率(Mvar)
- `res_trafo_max_loading_percent`: 最大负载率(%)

#### 2.2.2 负荷相关结果
- `res_load_sum_p_mw`: 负荷总有功功率(MW)
- `res_load_sum_q_mvar`: 负荷总无功功率(Mvar)
- `res_load_max_p_mw`: 负荷最大有功功率(MW)
- `res_load_max_q_mvar`: 负荷最大无功功率(Mvar)

#### 2.2.3 电源相关结果
- `res_gen_sum_p_mw`: 电源总有功功率(MW)
- `res_gen_sum_q_mvar`: 电源总无功功率(Mvar)
- `res_gen_max_p_mw`: 电源最大有功功率(MW)
- `res_gen_max_q_mvar`: 电源最大无功功率(Mvar)

#### 2.2.4 电源注入相关结果
- `res_feedin_sum_p_mw`: 电源注入总有功功率(MW)
- `res_feedin_sum_q_mvar`: 电源注入总无功功率(Mvar)

#### 2.2.5 母线相关结果
- `res_bus_sum_vm_pu`: 母线电压(pu)总和
- `res_bus_sum_p_mw`: 母线总有功功率(MW)总和
- `res_bus_sum_q_mvar`: 母线总无功功率(Mvar)总和
- `res_bus_max_vm_pu`: 母线电压(pu)最大值
- `res_bus_max_p_mw`: 母线有功功率(MW)最大值
- `res_bus_max_q_mvar`: 母线无功功率(Mvar)最大值

## 3. channel_data（通道数据）

每个通道连接两个站点，包含线路或开关信息。

### 3.1 基础信息字段
- `channel_name`: 通道名称，格式为"起点.电压等级_终点.电压等级"
- `from_station`: 起始站点ID
- `to_station`: 终止站点ID
- `coords`: 坐标数组，表示线路的起止点坐标
- `min_vn_kv`: 最小电压等级(kV)
- `max_vn_kv`: 最大电压等级(kV)

### 3.2 线路数据(line_data)
- `name`: 线路名称
- `type`: 类型，如"ac_line"
- `color`: 颜色标识(用于可视化)
- `vn_kv`: 额定电压(kV)
- `line_types`: 线路类型，如实线(solid)
- `index`: 索引
- `from_bus`: 起始母线索引
- `to_bus`: 终止母线索引
- `in_service`: 是否在运行状态
- `max_i_ka`: 最大电流(kA)
- `parallel`: 并联数
- `length_km`: 线路长度(km)
- `r_ohm_per_km`: 电阻(Ω/km)
- `x_ohm_per_km`: 电抗(Ω/km)
- `c_nf_per_km`: 电容(nF/km)
- `g_us_per_km`: 电导(μS/km)
- `from_bus_name`: 起始母线名称
- `to_bus_name`: 终止母线名称
- `isSequence`: 是否有序

### 3.3 开关数据(switch_data)
- `name`: 开关名称
- `closed`: 是否闭合状态
- `color`: 颜色标识(用于可视化)
- `in_ka`: 电流(kA)
- `line_types`: 线路类型，如实线(solid)
- `index`: 索引

### 3.4 计算结果字段(res_*前缀)
- `res_line_sum_p_from_mw`: 线路起始端总有功功率(MW)
- `res_line_sum_q_from_mvar`: 线路起始端总无功功率(Mvar)
- `res_line_sum_i_ka`: 线路总电流(kA)
- `res_line_sum_loading_percent`: 线路总负载率(%)
- `res_line_max_p_from_mw`: 线路起始端最大有功功率(MW)
- `res_line_max_q_from_mvar`: 线路起始端最大无功功率(Mvar)
- `res_line_max_i_ka`: 线路最大电流(kA)
- `res_line_max_loading_percent`: 线路最大负载率(%)
